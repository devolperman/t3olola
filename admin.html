🔌 فحص الاتصال بقاعدة البيانات

يختبر صلاحية القراءة والكتابة على Firebase Realtime Database.

مسار قاعدة البيانات: taaloola_menu
آخر تحديث: —

🔒 الأمان وحماية البيانات

  • ✅ قفل تلقائي: بعد 5 محاولات دخول خاطئة، يُقفل الدخول لمدة ساعة
  • ✅ القفل شامل: يستمر حتى بعد إعادة تحميل الصفحة (localStorage)
  • ✅ انتهاء الجلسة: الجلسة تنتهي تلقائياً بعد 4 ساعات
  • ✅ التشفير: كلمة المرور محمية بتشفير SHA-256 مزدوج مع "pepper"
  • ✅ الجلسة: تذكرة الدخول محفوظة في sessionStorage فقط (تزول بإغلاق المتصفح)
  • ✅ CSP: سياسة أمان المحتوى تمنع تنفيذ السكربتات الضارة
  • ✅ Firebase Rules: تأكد من ضبط قواعد الأمان من لوحة Firebase Console
  • ✅ الـ API Keys: مفاتيح Firebase عامة بتصميمها — الحماية الحقيقية من Security Rules
// Firebase Security Rules — الموصى بها:
{
  "rules": {
    "taaloola_menu": {
      ".read": true,
      "items": {
        ".write": "auth != null"
      },
      "categories": {
        ".write": "auth != null"
      },
      "settings": {
        ".write": "auth != null"
      },
      "orders": {
        ".write": "auth != null"
      }
    }
  }
}

⚠️ الصق هذه القواعد في Firebase Console → Realtime Database → Rules

⚠️ تنبيه أمني: هذا النظام يستخدم مصادقة محلية (Client-Side Auth) كحل مؤقت.
للتطبيق الإنتاجي، يوصى بشدة باستخدام Firebase Authentication مع Hosting لتأمين لوحة الإدارة بشكل كامل.
